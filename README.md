there are a set of instructions to run the backend in your system locally 
Every time you want to run the project
1. Open Command Prompt

Run:

cd /d C:\cybersecurity\cyberpriority-zero-cost-starter\backend
2. Activate the virtual environment
.venv\Scripts\activate

You should see:

(.venv) C:\cybersecurity\cyberpriority-zero-cost-starter\backend>
3. Start the backend
python -m uvicorn app.main:app --reload

You should see:

Uvicorn running on http://127.0.0.1:8000
Application startup complete.

Keep this CMD window open.

4. Open the dashboard

Open a second CMD window and run:

start "" "C:\cybersecurity\cyberpriority-zero-cost-starter\frontend\index.html"

Or simply double-click:

frontend\index.html

Your dashboard will open in the browser.

🔗 Backend/API addresses

Local API:

http://127.0.0.1:8000

Local API Documentation:

http://127.0.0.1:8000/docs
> These URLs are for local development only. The backend runs on localhost and is not publicly accessible.

🛑 When you want to stop the project

Go to the CMD window running Uvicorn and press:

CTRL + C

That's all.

You do not need to deactivate or delete the virtual environment.

🔄 Next time

You do NOT need to do these again:

❌ Install Python
❌ Create .venv
❌ pip install -r requirements.txt
❌ Install FastAPI
❌ Install Uvicorn

Those were setup steps.

Every future session is simply:

cd /d C:\cybersecurity\cyberpriority-zero-cost-starter\backend
.venv\Scripts\activate
python -m uvicorn app.main:app --reload

Then open the frontend.

🧹 Optional — remove simulated incidents

When you want to clear the incidents generated by the Simulate Attack button:

First stop the backend with:

CTRL + C

Then:

cd /d C:\cybersecurity\cyberpriority-zero-cost-starter\backend

Run:

python -c "import sqlite3; c=sqlite3.connect('cyberpriority.db'); n=c.execute(\"DELETE FROM incidents WHERE title LIKE 'Simulated %'\").rowcount; c.commit(); c.close(); print(f'Deleted {n} simulated incidents.')"

Then start the backend again:
